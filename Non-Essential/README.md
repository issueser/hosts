# Non-Essential Modules

Strict rules are applied to block certain non-essential functional modules, including but not limited to **meaningless advertisements, push notifications, NSFW content, etc**.  

## Important Notes

*   **Compatibility:** The `strict.txt` and `update.txt` files are specifically designed for **AdGuard Home**. While they may offer partial compatibility with other tools, their effectiveness and proper function are not guaranteed elsewhere.
*   **Browser Extension:** The `web_url.txt` file is tailored for the **AdGuard Chrome CRX (Extension ID: `bgnkhhnnamicmpeenaelnjfhikgbkllg`)**. Use in other browser extensions or software is not supported and may lead to unexpected behavior.

## File Descriptions

This project provides several rule files. Please choose the appropriate one based on your needs.

| File          | Designed For        | Purpose                                                                    |
|---------------|---------------------|----------------------------------------------------------------------------|
| `update.txt`  | AdGuard Home        | Exclusively for software and system updates.                               |
| `web_url.txt` | AdGuard Chrome CRX  | Dedicated to items found on web pages.                                     |
| `sim_login.txt`| General Use         | Specifically for "本机号码一键登录" (One-click login with mobile number network). |
| `strict.txt`  | AdGuard Home        | General-purpose strict rules aiming for comprehensive coverage.            |
